# Task: Define Challenge Protocol

**Assigned:** open
**Status:** open
**Priority:** high

## Description

Design the protocol for how challenges are distributed, executed, and results collected.

Key questions:
1. How does the coordinator distribute challenges?
2. How does a bot receive and acknowledge a challenge?
3. How are results submitted and verified?
4. What metadata is included (timing, token usage, etc.)?
5. How are results signed for accountability?

## Acceptance Criteria

- [ ] Protocol spec document
- [ ] Message format definitions (JSON schema)
- [ ] Sequence diagrams for challenge lifecycle
- [ ] Signing/verification mechanism defined
